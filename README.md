# 智能体从 0 到 1 学习网站

这是一个个人使用的“带学型”AI 智能体学习网站 MVP。

它不是资讯聚合站，也不是资料收藏夹。核心目标是帮助已经在 AI 行业工作、但对智能体研究不够深入的人，按照清晰学习路径逐步理解智能体，并通过每个主题配套的实操任务完成学习闭环。

## 产品定位

- 面向 AI 从业者的智能体系统学习工具
- 每次聚焦一个明确主题，降低认知负担
- 用文字、图示、视频、音频和实操任务组合讲清楚一个概念
- 实操任务优先设计成可以借助 Codex 完成
- 第一版先验证学习流程，不追求复杂后端和自动抓取

## MVP 范围

第一版只做最小可用学习闭环：

1. 首页：展示当前学习进度和推荐的“今天学什么”
2. 学习路径：按阶段展示智能体学习路线
3. 主题页：围绕一个主题完成多模态学习和实操闭环
4. Mock Data：所有课程、主题、资源和任务先集中用假数据管理

暂不做：

- 用户登录
- 社区讨论
- 新闻流
- 复杂后台
- 自动内容抓取
- 付费系统

## 第一版主题页结构

每个学习主题固定包含：

- 一句话定义
- 简明讲解
- 深入讲解
- 图示 / 结构化理解
- 视频资源
- 音频资源
- 今日实操任务
- 学习回顾 / 复盘问题

## 推荐技术方向

优先使用现代前端框架实现：

- Vite
- React
- TypeScript
- CSS Modules 或普通 CSS 变量体系
- 集中 mock data 文件

后续如果内容规模扩大，再考虑接入 MDX、数据库、搜索和真实资源接口。
